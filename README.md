### 🌌 Anti-Gravity Command Center
**Cyberpunk System Control & Application Launcher Panel for Linux Ubuntu**

![Status](https://img.shields.io/badge/Status-🟢%20ACTIVE-00F3FF?style=for-the-badge)
![Python](https://img.shields.io/badge/Python-3.9+-3776AB?style=flat-square&logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

[**➜ View Repository**](https://github.com/RyWethxss/anti_gravity_app) • [**📖 Full Documentation**](https://github.com/RyWethxss/anti_gravity_app#readme)

#### ✨ Key Features
- 🔌 **Plugin Architecture** — Dynamically load modules without touching core code
- 📡 **Event-Driven Bus** — Thread-safe Pub/Sub communication system
- 🎵 **Audio Visualization** — Real-time neon waveform spectrum analyzer
- 🎮 **Global Hotkeys** — Alt+Up/Down for volume, Alt+M for mute
- 📊 **Live System Monitor** — CPU, RAM, Disk, Uptime metrics
- 🎨 **Neon UI Theme** — Glassmorphism design with deep purple & cyan
- ⌨️ **Keystroke HUD** — Visual feedback of pressed keys with smooth animations

#### 🏗️ Architecture
```
Event Bus (Thread-Safe)
    ↓
[Audio Module] [Launcher Module] [Stats Module] [Custom Plugins]
    ↓              ↓                  ↓
PyQt6 UI Components (QThreads)
    ↓
System Control (PulseAudio, psutil, pynput)
```
